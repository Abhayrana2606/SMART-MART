# Smart Mart 🛒

Smart Mart is a simple e-commerce web application made for learning and training purposes.  
The project provides basic online shopping features with a clean and user-friendly interface.

## 🚀 Features
- User Login & Signup
- Product Listing
- Add to Cart
- Search Products
- Responsive Design

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
